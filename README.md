# October Calendar 2026

Готовый статический календарь для GitHub Pages.

- 31 день: 1–31 октября 2026.
- Каждый день открывается автоматически в 10:00 МСК.
- До открытия карточка чёрно-белая, после — цветная и кликабельная.
- Окно каждого дня пока оставлено пустым.
- Работает без backend, базы данных и npm.

## Публикация на GitHub Pages

1. Загрузите содержимое папки в корень репозитория.
2. Откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**.
4. Branch: `main`, folder: `/ (root)`.
5. Сохраните настройки.

Позже содержимое пустого окна можно заполнять любым форматом, не меняя механику календаря.
