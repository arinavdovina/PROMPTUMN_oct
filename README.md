# FreshTeacher — October Prompt Calendar 2026

Готовый статический сайт для GitHub Pages.

## Что внутри
- 31 карточка: 1–31 октября 2026.
- Каждая дата открывается автоматически в **10:00 по Москве (UTC+3)**.
- До открытия карточка чёрно-белая и некликабельная.
- После открытия становится цветной; внутри **3 готовых промпта**.
- Всего **93 промпта** для преподавателей иностранных языков.
- Кнопки копирования одного промпта и всего набора.
- Адаптивная версия для компьютеров и телефонов.
- Никакого backend, базы данных или npm.

## Публикация на GitHub Pages
1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите **содержимое этой папки в корень репозитория** (`index.html`, `styles.css`, `script.js`, `assets`, `.nojekyll`).
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**.
5. Branch: `main`, folder: `/ (root)` → Save.
6. Через несколько минут GitHub покажет публичную ссылку.

## Важно
Дата разблокировки вычисляется по фиксированному московскому времени. Пользователь может находиться в любой стране: карточки всё равно открываются в 10:00 МСК.

Все тексты промптов находятся в `script.js` в массиве `DAYS`, поэтому их можно менять без перестройки интерфейса.
